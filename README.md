# 🚦 Modelo Oculto de Markov (HMM)
## Simulación Inteligente de Tráfico Vehicular

Proyecto académico desarrollado en **Python** y **Google Colab** para simular el comportamiento probabilístico del tráfico vehicular utilizando un **Modelo Oculto de Markov (HMM)**.

---

# 📌 Descripción del Proyecto

Este proyecto implementa un HMM para representar diferentes estados del tráfico vehicular mediante simulaciones probabilísticas.

El sistema utiliza:
- estados ocultos,
- observaciones visibles,
- matrices de transición,
- matrices de emisión,
- y análisis estadístico.

El objetivo es analizar el comportamiento del tráfico durante múltiples simulaciones y estudiar la convergencia del modelo hacia una distribución estacionaria.

---

# 🎯 Objetivo

Aplicar conceptos de:
- probabilidad,
- estadística,
- simulación,
- y Modelos Ocultos de Markov,

mediante un sistema de tráfico vehicular implementado en Python.

# 🧠 Componentes del HMM

## 📍 Distribución Inicial

Define la probabilidad de iniciar en cada estado del sistema.

---

## 🔄 Matriz de Transición

Representa las probabilidades de cambio entre estados ocultos.

---

## 👀 Matriz de Emisión

Representa las probabilidades de generar observaciones visibles.
